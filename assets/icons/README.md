# Icons Directory

This directory should contain custom icons for the application.

## Recommended Icons

The following icons should be added to this directory:

- app_icon.png (512x512) - Main application icon
- favicon.ico (32x32) - Browser favicon
- Custom SVG icons for specific UI elements if needed

## Current Status

Currently using Material Design icons from Flutter's built-in icon set. Custom icons can be added here if needed for branding purposes.

## Adding Icons

1. Place icon files in this directory
2. Update pubspec.yaml to reference the icons
3. Run `flutter pub get` to update assets
